🍲 KHDL Food Recommendation

Hệ thống Gợi Ý Món Ăn Dựa Trên Knowledge Graph

📋 Tổng Quan Project

Mục đích: Xây dựng một hệ thống gợi ý món ăn thông minh bằng cách:

  • Crawl dữ liệu công thức nấu ăn từ Cookpad và các nguồn khác
  • Chuẩn hóa và xử lý dữ liệu (tên nguyên liệu, khối lượng, loại món)
  • Xây dựng Knowledge Graph (đồ thị kiến thức) để biểu diễn quan hệ giữa các đơn vị
  • Lưu trữ KG trong Neo4j database
  • Gợi ý món ăn dựa trên nguyên liệu sẵn có và tiêu chí của người dùng

🎯 Refactored Pipeline Control (src/)

Cấu trúc mới để kiểm soát pipeline:

  • src/config.py - Cấu hình tập trung (paths, Neo4j credentials)
  • src/ontology.py - Định nghĩa schema KG
  • src/pipeline.py - Lớp PipelineOrchestrator (kiểm soát workflow)
  • src/__main__.py - CLI entry point: python -m src [command]

Standalone scripts (scripts/):

  • scripts/status.py - Kiểm tra trạng thái pipeline
  • scripts/normalize.py - Chỉ normalize CSV → JSON
  • scripts/build_kg.py - Chỉ build KG
  • scripts/recommend.py - Chỉ tạo recommendations
  • scripts/pipeline.py - Chạy toàn bộ pipeline

🔧 Các Module Chính

📥 1. Crawl Module (Crawl/)

Chức năng: Thu thập dữ liệu công thức nấu ăn từ các website

File chính:

  • data_crawl_CP.py - Crawl từ Cookpad (tên, cách nấu, nguyên liệu, thời gian, độ khó)
  • data_crawl_MNMN.py - Crawl từ các nguồn khác

Output: File CSV chứa dữ liệu thô (raw_data_CP.csv)

� 2. NLP Processor Module (nlp-processor/)

Chức năng: Xử lý NLP tiếng Việt và chuẩn hóa dữ liệu thô thành định dạng chuẩn

File chính:

  • Ingredients_Parser.ipynb - Jupyter Notebook xử lý NLP (để phát triển & test)
  • nlp-processor.py - Python script (chạy từ shell/pipeline)

Xử lý NLP:

  • Sử dụng thư viện underthesea để tokenization tiếng Việt
  • Phân loại nguyên liệu (chính/phụ bắt buộc/phụ tùy chọn)
  • Chuẩn hóa tên nguyên liệu tiếng Việt với từ điển sẵn có
  • Tách khối lượng và đơn vị (g, kg, ml, l, muỗng, cái, bó, củ...)
  • Chuyển đổi đơn vị thành gram chuẩn
  • Xác định loại món ăn từ tên

Output: File JSON chuẩn (recipes_processed.json)

🎯 Knowledge Graph Ontology

Knowledge Graph được xây dựng với các node types và relations sau:

Node Types (Các loại Node)

Node Type Key Property Mô Tả
Dish name Các công thức nấu ăn (tên, thời gian, phục vụ bao nhiêu người, độ khó)
DishType name Loại món ăn (mặn, canh, rau, chay, soup, khai vị...)
Ingredient canonical_name Nguyên liệu chuẩn (tên chính thức, tên hiển thị)
StockItem name Nguyên liệu sẵn có trong kho (tên, khối lượng)
Difficulty name Mức độ khó: Dễ, Trung bình, Khó

Relationships (Các Mối Quan Hệ)

Quan Hệ Từ Đến Mô Tả
HAS_TYPE Dish DishType Món ăn thuộc loại nào
HAS_INGREDIENT Dish Ingredient Món ăn cần nguyên liệu nào (với khối lượng, nhóm)
REFERS_TO StockItem Ingredient Nguyên liệu kho tương ứng với nguyên liệu chuẩn nào
HAS_DIFFICULTY Dish Difficulty Môn ăn có mức độ khó nào

🚀 Thứ Tự Chạy Project

Bước 1: Chuẩn Bị Dữ Liệu

  • Crawl dữ liệu từ Cookpad
    python code/Crawl/data_crawl_CP.py

    Output: result/raw_data_CP.csv (dữ liệu thô)

  • Chuẩn hóa dữ liệu với NLP Processor

    Sử dụng Python script:

    python nlp-processor/nlp-processor.py result/raw_data_CP.csv result/recipes_processed.json

    Hoặc: Sử dụng Jupyter Notebook (để phát triển):

    jupyter notebook nlp-processor/Ingredients_Parser.ipynb

    Output: result/recipes_processed.json (dữ liệu chuẩn dạng JSON)

Bước 2: Xây Dựng Knowledge Graph

  • Export Payload và Cypher Commands

    Lệnh:

    python code/KG/run_pipeline.py export

    Output:

    • result/kg_payload.json - Payload cho KG
    • result/load_kg.cypher - Script Cypher để load vào Neo4j

    Chú ý:

    • Mặc định sử dụng file: result/recipes_processed.json (từ NLP processor)
    • Để dùng file khác: python code/KG/run_pipeline.py export --recipe-file result/your_file.json
    • Đảm bảo đã có file stock: data/Kho.json

Bước 3: Load Vào Neo4j Database

  • Load vào Neo4j Local

    Lệnh:

    python code/KG/run_pipeline.py load-neo4j \
        --uri bolt://localhost:7687 \
        --user neo4j \
        --password YOUR_PASSWORD \
        --database neo4j \
        --clear

    Thay thế YOUR_PASSWORD bằng mật khẩu Neo4j của bạn

  • Hoặc load vào Neo4j Aura (Cloud)

    Lệnh:

    python code/KG/run_pipeline.py load-neo4j \
        --uri neo4j+s://YOUR_INSTANCE.databases.neo4j.io \
        --user YOUR_USER \
        --password YOUR_PASSWORD \
        --database neo4j \
        --clear

    Lấy thông tin từ Neo4j Aura console

Bước 4: Chạy Gợi Ý Món Ăn

  • Sử dụng CLI (Command Line)

    Lệnh cơ bản:

    python code/KG/run_pipeline.py recommend \
        --top-k 10 \
        --max-dishes 3

    Tham số:

    • --top-k 10 - Giữ 10 món ăn hàng đầu
    • --max-dishes 3 - Chọn 3 món cho meal set
    • --max-minutes 60 - Thời gian nấu tối đa 60 phút (tùy chọn)
    • --dish-type canh - Lọc theo loại món (tùy chọn)
    • --required-type canh --required-type rau - Yêu cầu phải có loại này (tùy chọn)

    Output: result/recommendation_kg.json

  • Sử dụng GUI (Giao Diện Đồ Họa)

    Lệnh:

    python code/KG/gui_test.py

    Tính năng:

    • Chọn số lượng món ăn muốn gợi ý (2-5)
    • Chọn thời gian nấu tối đa
    • Chọn loại món ăn (mặn, canh, rau, chay...)
    • Tùy chọn "Không lọc theo loại" để tick nhiều loại
    • Xem kết quả gợi ý trực tiếp trong giao diện

🎲 Thuật Toán Gợi Ý Món Ăn

1. Tính Điểm Món Ăn (Scoring)

Với mỗi món ăn, hệ thống tính điểm dựa trên:

  • Nguyên liệu chính (60%): Những nguyên liệu quan trọng
  • Nguyên liệu phụ bắt buộc (35%): Những nguyên liệu phụ cần thiết
  • Nguyên liệu phụ tùy chọn (5%): Những nguyên liệu có thể bỏ qua

Với mỗi nguyên liệu, so sánh:

  • Tên nguyên liệu (70%): Tương đồng semantic với embedding
  • Khối lượng có sẵn (30%): Ratio giữa khối lượng cần và có sẵn

2. Chọn Meal Set (Selection)

Từ top-k món ăn có điểm cao nhất, chọn max-dishes món:

  • Tối ưu hóa: Tổng điểm cao nhất
  • Ưu tiên: Bao phủ các loại món ăn yêu cầu (nếu có)
  • Đảm bảo: Tất cả nguyên liệu chính có sẵn

⚙️ Cấu Hình Và Cài Đặt

Cài Đặt Dependencies

pip install -r requirements.txt

Cập Nhật config.py

Chỉnh sửa file code/KG/config.py nếu cần:

  • DEFAULT_RECIPE_FILE - Mặc định: result/recipes_processed.json (từ NLP processor)
  • DEFAULT_STOCK_FILE - Mặc định: data/Kho.json (danh sách nguyên liệu kho)
  • DEFAULT_NEO4J_URI - URI kết nối Neo4j
  • DEFAULT_NEO4J_USER - User Neo4j
  • DEFAULT_NEO4J_PASSWORD - Password Neo4j (cập nhật nếu dùng local)
  • DEFAULT_NEO4J_DATABASE - Tên database Neo4j

File Format

data/Kho.json: Danh sách nguyên liệu kho có sẵn

[
  {
    "name": "Cà chua",
    "quantity": 500,
    "unit": "g"
  },
  ...
]

result/recipes_processed.json: Danh sách công thức nấu ăn (output từ NLP processor)

{
  "total": 95,
  "recipes": [
    {
      "name": "MÌ spaghetti sốt tôm-rau củ",
      "main_ingredients": {"mì": 200.0, "tôm": 100.0},
      "required_ingredients": {"cải xanh": 1, ...},
      "optional_ingredients": ["hành tây", "muối", "tiêu"]
    },
    ...
  ]
}
